**不兼容变更**：删除 Modbus 卡片的轮询表和轮询开关（`pollList`、`pollMode`、`autoStart`），文件里再出现这些键时按未知属性忽略，`tools/check_uidp.py` 报"没有属性"；删除绑定和曲线的寄存器区"响应内序号"，Modbus 绑定一律按寄存器区和寄存器地址取值，旧工程请给每个 Modbus 绑定和 Modbus 曲线选寄存器区（不选时是保持寄存器）并填寄存器地址；Modbus 卡片变为可选，不放它也会自动读取。没有升级或兼容处理，旧工程按上面的说明改一次即可。`.uidp` 工程与 FluentHMI Studio 0.2.1 互通。

- Modbus 自动轮询：只要在控件上绑定寄存器地址，程序就自动读取，不用放轮询卡片，也不用点按钮。运行后（设计器预览和导出的程序都一样），一旦有用 `modbus` / `modbus_tcp` / `modbus_ascii` 解析的链路能发送（监听的 TCP 服务端要已有客户端），就按控件的 Modbus 绑定和实时曲线的 Modbus 曲线规划读取：同一从站、同一功能码里相近的地址合并成一块（寄存器间隔 ≤ 8、一块 ≤ 120 个，线圈和离散输入间隔 ≤ 64、一块 ≤ 1000 个），每块按绑定新增的「采集周期(ms)」（`mbPeriod`，0 用默认周期）读取，只读界面上看得见的控件，选项卡其他页上的不读。没有 Modbus 卡片时默认周期 500 ms、响应超时 1000 ms、不过滤从站的绑定读从站 1。规划规则与 FluentHMI Studio 用同一份向量文件（`tests/data/poll_plan_vectors.json`）测试。
- 每条链路有一个 Modbus 主站队列，一次只有一个请求在线上，写命令排在读请求前面，按按钮写入不会再和在途的读请求撞车。
- Modbus 卡片是轮询的参数、状态和手动收发面板：文档里第一张卡片的「轮询ms」（0 为 500 ms，运行中改了立即生效）、响应超时和默认从站就是轮询的参数，放几张卡片也只有一套读请求；每张卡片的状态栏显示"N 块 · 轮询中 / 正常"、"第 k 块无响应（从站 S 功能码 F 地址 A）"、"第 k 块异常 02 非法数据地址"、"等待连接"、"没有 Modbus 绑定"或"已暂停"，鼠标悬停列出各块的从站、功能码、地址和周期；「停止」/「轮询」暂停和继续轮询（所有卡片共用）；「发送」随时可用，请求排在下一次读之前，轮询中结果用 2 秒的通知显示，暂停时显示在状态栏；字段组不成请求时状态栏显示"参数无效"（原因用通知显示），没有链路接收时显示"发送失败，请检查连接"。卡片的「轮询ms」提示改为"默认 500"。
- 串口 / TCP / MQTT 配置卡片只保留一个「连接/断开」按钮（连接中显示「取消」），放在最后一行字段的右端，不再单占一行；默认尺寸改为串口 360×320、TCP 360×250、MQTT 380×390。卡片不会再比内容矮：运行时按字段需要的高度显示，设计器按内容限制最小高度（拖拽、属性面板、切换显示方式时都一样），打开旧工程时太矮的卡片会抬到放得下字段的高度。
- 设计器：Modbus 绑定和曲线的「寄存器区」只有保持寄存器（默认）、输入寄存器、线圈、离散输入四项，地址一行固定叫「寄存器地址」；Modbus 绑定的最后一行是「采集周期(ms)」，提示"0 = 用默认周期（500 ms，或 Modbus 卡片的轮询 ms）"。属性面板隐藏的行不再留下空白。`check_uidp.py` 校验 `mbPeriod`，Modbus 绑定和 Modbus 曲线的 `mbArea` 写"响应内序号"时报错。
- 示例：`02-温控仪监控.uidp` 和 `10-PLC恒压供水.uidp` 去掉了 Modbus 卡片，只留链路卡片和按寄存器地址绑定的控件，并重新排了版（02 的绑定选了保持寄存器，10 去掉了轮询表）；两个工程连上设备即按默认的 500 ms 自动读取。`examples/tutorials/README.md` 随之更新。
