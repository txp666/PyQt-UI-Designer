**不兼容变更**：删除 Modbus 配置卡片（`ModbusConfigCard`），含它的旧工程需手工删掉该控件（打开时报 `未知控件类型: ModbusConfigCard`，`tools/check_uidp.py` 也这样报告）；轮询参数改在链路卡片上。卡片的轮询表（`pollList`、`pollMode`、`autoStart`）、「停止」/「轮询」和「发送」随卡片一起去掉：轮询总是自动进行，手动读写寄存器用按钮、输入框、开关等控件的 Modbus 命令模式。删除绑定和曲线的寄存器区"响应内序号"，Modbus 绑定一律按寄存器区和寄存器地址取值，旧工程请给每个 Modbus 绑定和 Modbus 曲线选寄存器区（不选时是保持寄存器）并填寄存器地址。没有升级或兼容处理，旧工程按上面的说明改一次即可。`.uidp` 工程与 FluentHMI Studio 0.2.1 互通。

- Modbus 自动轮询：链路卡片选 Modbus 解析、控件绑定寄存器地址即可自动读取，不用点按钮。运行后（设计器预览和导出的程序都一样），一旦有用 `modbus` / `modbus_tcp` / `modbus_ascii` 解析的链路能发送（监听的 TCP 服务端要已有客户端），就按控件的 Modbus 绑定和实时曲线的 Modbus 曲线规划读取：同一从站、同一功能码里相近的地址合并成一块（寄存器间隔 ≤ 8、一块 ≤ 120 个，线圈和离散输入间隔 ≤ 64、一块 ≤ 1000 个），每块按绑定新增的「采集周期(ms)」（`mbPeriod`，0 用链路卡片的默认轮询）读取，只读界面上看得见的控件，选项卡其他页上的不读。规划规则与 FluentHMI Studio 用同一份向量文件（`tests/data/poll_plan_vectors.json`）测试。
- 每条链路有一个 Modbus 主站队列，一次只有一个请求在线上，写命令排在读请求前面，按按钮写入不会再和在途的读请求撞车。
- 串口 / TCP / MQTT 配置卡片新增三个属性：「默认轮询(ms)」（`modbusPeriod`，默认 500）、「响应超时(ms)」（`modbusTimeout`，默认 1000）和「默认从站」（`modbusSlave`，默认 1，给不过滤从站的绑定用），属性面板里只在卡片的解析模式选了 modbus / modbus_tcp / modbus_ascii 时显示（选「项目设置」时隐藏，值照样保存、照样生效），运行中改了立即生效。轮询用链路已连上并解析 Modbus 的卡片的设置，有几张时用文档里的第一张，没有时用这三个默认值。这样的卡片在状态栏的连接信息后面显示轮询状态，如"● 已连接 · 3 块 · 正常"，其余还有"N 块 · 轮询中"、"第 k 块无响应（从站 S 功能码 F 地址 A）"、"第 k 块异常 02 非法数据地址"和"没有 Modbus 绑定"，鼠标悬停列出各块的从站、功能码、地址和周期。
- 串口 / TCP / MQTT 配置卡片只保留一个「连接/断开」按钮（连接中显示「取消」），放在最后一行字段的右端，不再单占一行；默认尺寸改为串口 360×320、TCP 360×250、MQTT 380×390。卡片不会再比内容矮：运行时按字段需要的高度显示，设计器按内容限制最小高度（拖拽、属性面板、切换显示方式时都一样），打开旧工程时太矮的卡片会抬到放得下字段的高度。状态文字过长时只占标题右边剩下的地方，不再挤压标题。
- 设计器：Modbus 绑定和曲线的「寄存器区」只有保持寄存器（默认）、输入寄存器、线圈、离散输入四项，地址一行固定叫「寄存器地址」；Modbus 绑定的最后一行是「采集周期(ms)」，提示"0 = 用默认周期（链路卡片的「默认轮询(ms)」，默认 500）"。属性面板隐藏的行不再留下空白。`check_uidp.py` 校验 `mbPeriod`，Modbus 绑定和 Modbus 曲线的 `mbArea` 写"响应内序号"时报错。
- 示例：`02-温控仪监控.uidp` 和 `10-PLC恒压供水.uidp` 去掉了 Modbus 卡片，只留链路卡片和按寄存器地址绑定的控件，并重新排了版（02 的绑定选了保持寄存器，10 去掉了轮询表）；两个工程连上设备即按链路卡片默认的 500 ms 自动读取。`examples/tutorials/README.md` 随之更新。
- 文档：`docs/protocol.md` 的 Modbus 部分改写为「接 PLC：自动轮询」（参数和状态在链路卡片上，手动读写用控件的 Modbus 命令模式）；`docs/uidp-format.md`、`docs/uidp-widgets.md`、README 同步。
- 导出的程序运行时代码同步更新（`serial_handler.py` 里新增每条链路的 Modbus 请求队列，`data_binding.py` 里新增轮询调度器 `ModbusPoller`，`ui.py` 的链路卡片带上轮询参数和状态，`tcp_handler.py`、`mqtt_handler.py` 随之更新），独立 demo 已重新生成。运行依赖没有变化。
