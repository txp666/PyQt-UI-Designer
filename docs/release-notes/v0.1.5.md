本版本新增“小数位数”属性，重做仪表盘，修复实时曲线随读数左右晃动的问题，并附上视频教程里搭建的示例工程。

- 新增“小数位数”：数值显示和标签可设为 0～4 位。转换表达式算出的长小数（如 `value * 3.3 / 4095` 得到的 1.6117948717948718）按设定位数显示为 1.61；显示格式为十进制、十六进制或二进制时不受影响。设计器预览和导出的程序一致。
- 重做仪表盘：270° 表盘居中，不再被裁切，线宽随尺寸缩放；数值和单位同行显示，标题在下方，两端标出最小值和最大值。设计器和导出的程序使用同一份实现。
- 修复实时曲线右侧读数在整数和小数之间切换（如 100 和 99.82）时，读数区宽度变化带动整条曲线左右晃动的问题；游标读数和“实时”之间切换时同样保持稳定。
- 修复编译后的程序在切换页面后很快关闭窗口时，页面切换动画结束仍访问已销毁控件而报错的问题。
- 新增 `examples/tutorials/`：7 期视频教程里搭建的工程，包括温湿度采集、Modbus 温控仪、HEX 电机控制板、JSON 环境监测站、AT 指令调试助手、PID 调参助手和 ADC 采集板，附各自的数据格式说明，可以直接打开、预览或导出。
- 同步更新独立 demo 的导出代码。

提供 Windows x64、macOS Apple Silicon（arm64）、macOS Intel（x64）独立运行包及 SHA-256 校验文件。解压后运行 `main.exe` 或 `.app`，无需安装 Python。

Mac 安装包未做 Apple Developer ID 签名与公证；Windows 安装包未做 Authenticode 签名。通信验证使用模拟设备和软件测试，实际硬件仍需按设备协议联调。
