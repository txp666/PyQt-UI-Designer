本补丁修复最终安装包实测中发现的 Qt 生命周期问题，建议使用 v0.1.4 替代 v0.1.3。

- 修复 Nuitka 编译后，停止、重启预览仍可能向已销毁的串口卡片、日志、图表等控件发送信号的问题；控件销毁时显式解除外部信号连接，并忽略已经排队的旧回调。
- 修复替换窗口标题栏后，标题或图标变化仍访问旧标题栏的问题，设计器与导出的程序采用相同处理。
- 修复带有选中控件的画布退出时仍回调已销毁视图，以及检查更新过程中关闭窗口导致运行中的线程被销毁的问题。
- 加强发布包测试：直接运行解压后的应用，覆盖工程加载、全部控件预览、连续启停、串口信号、主题切换、代码导出及正常退出；出现 Qt 回调异常即判定失败。
- 同步更新独立 demo；修正文档中的键值格式、Modbus CRC 示例和 STM32 HEX 示例字节序。

保留 v0.1.3 的预览与导出一致性修复，包括主题、Tab 坐标、控件层次、数值范围、相对图片路径、命令编码、数据绑定及串口发送失败处理。

提供 Windows x64、macOS Apple Silicon（arm64）、macOS Intel（x64）独立运行包及 SHA-256 校验文件。解压后运行 `main.exe` 或 `.app`，无需安装 Python。

Mac 安装包未做 Apple Developer ID 签名与公证；Windows 安装包未做 Authenticode 签名。通信验证使用模拟设备和软件测试，实际硬件仍需按设备协议联调。
