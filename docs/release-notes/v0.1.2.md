新增 macOS 支持，提供 Apple Silicon（arm64）和 Intel（x64）安装包，同时保留 Windows x64 版本。

- 修复 Mac 串口设备路径被转为大写的问题，导出的上位机程序同步修复。
- 适配 Mac 字体、Retina 图标、Delete 键及触控板滚动；支持 Command + 滚动缩放画布。
- 支持生成独立 `.app`，打包后可在 Finder 打开输出目录。
- 打包器支持 Python 3.10+，兼容 Finder 启动时的 Python 查找；缺少依赖时创建项目内虚拟环境，避免修改 Homebrew 系统 Python。
- 修复空项目导出语法错误，以及找不到编译产物时误报打包成功的问题。
- 增加 Windows、Mac arm64 和 Mac Intel 自动检查，并在发布前验证解压后的应用能够启动。

下载对应平台的 zip 并解压：Mac 打开其中的 `.app`，Windows 运行 `main.exe`。每个安装包都提供 `.zip.sha256` 校验文件。

安装包内置 Python 和 Qt，运行不需要另装 Python。使用应用内“一键打包”仍需要 Python 和本机编译工具；Mac 使用 Xcode Command Line Tools。

Mac 安装包未做 Apple Developer ID 签名与公证；Windows 安装包未做 Authenticode 签名。串口软件路径和虚拟端口收发已验证，具体 USB 转串口设备及驱动仍需在对应硬件上确认。
