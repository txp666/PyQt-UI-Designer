本版本面向 PLC 和各种自定义协议的设备：Modbus 补齐了按地址取值、多寄存器写入和轮询表，新增可配置长度字段和校验的二进制帧解析、可配置结束符和编码的文本解析，以及 Modbus ASCII。设计器预览和导出的程序行为一致，`.uidp` 工程与 FluentHMI Studio 0.2.0 互通。

- Modbus：读响应按寄存器地址命名（`hr100`、`ir0`、`co3`、`di0`），绑定和曲线新增"寄存器区"选项，轮询多块地址时不再分不清是哪块的响应；按钮、输入框、下拉框、滑块、数值框可以发 FC16 写多个寄存器，值的类型（uint16 / int16 / uint32 / int32 / float32）和寄存器序可选。Modbus 卡片新增轮询表（多行 `从站,功能码,地址,数量`）和响应超时，一次只发一条请求，状态显示"轮询正常 · N/M"、无响应的条目和设备返回的异常码。
- 二进制帧（`hex` 解析模式）：帧头、帧尾可以只填一个或都不填，新增长度字段（偏移、字节数、字节序，长度数的是数据 / 长度字段之后 / 整帧）、固定帧长、和校验 / 异或 / CRC8 / CRC16-Modbus / CRC16-CCITT 校验（可设起点和字节序）、空闲超时分帧；字段表支持字节序和 uint8 … float64、ASCII、HEX 十种类型。用 `hex` 模式的链路把整帧交给 HEX字节提取 和曲线，控件上不必再填帧头帧尾。
- 文本（`line` 解析模式）：行结束符、键值分隔符（`=` 或 `:`）和编码（UTF-8 / GBK / ASCII）可配；`$…*HH` 的 NMEA 语句自动校验；JSON 不再要求一行一条，多行格式化、连着发、顶层数组都能解析。
- 新增 Modbus ASCII 解析模式 `modbus_ascii`，Modbus 命令在这类链路上自动按 ASCII 组帧；新增 FC 07、08、17、22、23 响应的解析。
- 设计器：未选中控件时编辑工程的「默认帧格式」，串口 / TCP / MQTT 卡片可以各自设置帧格式（`parserConfig`）；开关、滑块、数值框也有数据绑定卡片；Modbus 模式的发送设置不再随"发送开关"隐藏。曲线图的曲线选择改成图内图例。
- 显示：数据接收卡片按链路的编码显示文本，GBK 设备的日志不再乱码；"自动"显示格式去掉二进制运算的尾数噪声（`26.700000000000003` 显示为 `26.7`）。
- 新增示例 `examples/tutorials/10-PLC恒压供水.uidp`：Modbus TCP 轮询、按地址绑定、float32 写入。
- 文档：`docs/protocol.md` 新增二进制帧、文本解析规则和 Modbus ASCII 章节，`docs/uidp-format.md` 同步；`check_uidp.py` 校验新的解析设置。
- 导出的程序运行时代码同步更新（`serial_handler.py`、`tcp_handler.py`、`mqtt_handler.py`、`comm_hub.py`），独立 demo 已重新生成。运行依赖没有变化。

`.uidp` 文件向后兼容：旧工程的 `hex` 配置（只有帧头、帧尾、字段表）和 Modbus 绑定按原样工作。
