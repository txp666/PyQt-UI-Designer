# PyQt UI Designer 0.7.0

- Add classic Siemens S7comm through the official Snap7 native library. Independent S7 connection cards support typed DB/M/I/Q bindings, live curves and writes directed to the selected PLC. Types: BOOL, BYTE, SINT, WORD, INT, DWORD, DINT and REAL; BOOL writes preserve neighboring bits.
- Preview, generated Python source and Nuitka applications share the S7 backend. Windows and macOS packages include the native library and license notices; exported S7 applications carry the library too. Background workers serialize I/O and discard stale results and queued writes after disconnect.
- Projects using S7 save as UIDP 1.1; ordinary projects remain at 1.0. Older designers cannot open S7 projects. See [S7 setup and limits](https://github.com/txp666/PyQt-UI-Designer/blob/v0.7.0/docs/s7.md) and the [paired PLC examples](https://github.com/txp666/PyQt-UI-Designer/tree/v0.7.0/examples/s7). Use [FluentPLC Simulator](https://github.com/txp666/FluentPLC-Simulator) for local testing. This implements classic absolute-address S7comm; S7CommPlus and optimized/symbolic DB access are outside its scope.
- Exported application canvases now fit the window as it resizes.
- Switch feedback supports Modbus registers and configurable ON conditions, including non-zero values, consistently in preview and exported source.
- Settings and both READMEs link the repository, related HMI tools and the PLC simulator.

## 简体中文

- 新增经典西门子 S7comm，基于官方 Snap7 原生库。独立 S7 连接卡片支持 DB/M/I/Q 类型化绑定、实时曲线和定向写入，支持 BOOL、BYTE、SINT、WORD、INT、DWORD、DINT、REAL，BOOL 位写保留邻位。
- 预览、导出 Python 源码和 Nuitka 应用共用 S7 后端。Windows、macOS 安装包和导出的 S7 应用随附平台原生库及许可说明；后台线程串行处理读写，断开后丢弃旧会话结果和待发写入。
- S7 工程保存为 UIDP 1.1，其他工程保持 1.0；旧版设计器无法打开 S7 工程。提供[配置与范围说明](https://github.com/txp666/PyQt-UI-Designer/blob/v0.7.0/docs/s7.md)和[双 PLC 示例](https://github.com/txp666/PyQt-UI-Designer/tree/v0.7.0/examples/s7)，可搭配 [FluentPLC Simulator](https://github.com/txp666/FluentPLC-Simulator) 本地验证。当前支持经典绝对地址 S7comm，不包含 S7CommPlus、优化 DB 或符号访问。
- 导出应用画面随窗口大小自动适配。
- 开关支持 Modbus 寄存器反馈及可配置 ON 判定条件，包括非零为 ON，预览与导出源码保持一致。
- 设置及中英文 README 增加仓库、相关 HMI 工具和 PLC 模拟器链接。
