- Modbus RTU / TCP 从站：串口、TCP、UDP 卡片可以当从站，应答外部主站；新增从站寄存器表控件和示例「11-温控仪模拟器」。
- 新增 UDP 链路卡片；同种链路卡片可以放多张，各连各的。
- 发命令新增 JSON 模式，按模板发送，自动转义。
- 图片显示新增旋转、水平 / 垂直镜像和缩放方式。
- 界面支持中文 / English 切换。默认跟随系统，英文系统下显示英文，可在设置 → 语言改回中文。

## English

- Modbus RTU / TCP slave: serial, TCP and UDP cards can answer an external master, with a new slave register table widget and the example "11-温控仪模拟器".
- A new UDP link card; any number of link cards of the same kind, each with its own connection.
- A JSON send mode for commands, built from a template and escaped automatically.
- Image displays gain rotation, horizontal / vertical mirroring and a scale mode.
- The interface switches between Chinese and English. It follows the system by default, so an English system shows English; change it under Settings → Language.
- Tooltips, dialogs, scroll bars and more use Fluent components.
