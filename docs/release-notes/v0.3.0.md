## English

- The designer has undo / redo (up to 100 steps) and copy / paste, with a clipboard FluentHMI Studio shares; widget JSON written in the `.uidp` format pastes too.
- The toolbar shows icons, the same buttons in the same order as FluentHMI Studio's: New, Open and Save move onto it with a new Save As, the align menu gains centring, and it adds a grid switch, Fit and Actual size, with switches at its ends that hide or show the palette and the property panel. A canvas larger than the view opens fitted.
- The palette has redrawn icons, and the link cards, send/receive cards and log box are grouped as 通信控件.
- A project can name an app icon (`icon` in `.uidp`); exported code and packaged programs use it.
- The real-time chart's readings move above the plot, which takes the full width; its save and load buttons show icons.
- Settings add a theme colour; the Mica switch shows only on Windows and is disabled before Windows 11.
- Distributing widgets now makes the gaps between them equal.
- Fix: with several register blocks on a link, Modbus polling sometimes read a block a period late.
