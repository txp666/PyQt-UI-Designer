本版本修复设计器、运行预览和独立导出程序之间的行为差异，并更新可独立运行的串口采集 demo。

- 切换工程或修改设计后停止旧预览，避免继续发送旧工程命令；修复反复启停预览时访问已销毁控件的问题。
- 统一预览和导出的 HEX、二进制数值及 Modbus 命令编码，拒绝非法地址、越界数值和非有限数；发送失败不再显示成功。
- 修复串口切换解析模式时错误沿用旧配置，以及断开、重连和控件销毁后的信号处理。
- 修复 Tab 子控件位置偏移、重叠控件层次反转、上下限处理差异和仪表显示越界；相对图片路径在设计器、预览和导出中一致解析。
- 保留导出控件的标题、默认值、禁用及只读状态等配置；修复表格、日志接收数据、进度环百分比和 ASCII 空字段更新。
- 修复主题切换影响预览和导出显示的问题；曲线异常样本不会中断其他通道，历史文件校验失败保留现有数据，同名通道保存不丢数据。
- 导出支持含特殊字符的控件 ID，并先完成代码生成及语法检查，避免配置错误覆盖已有导出文件。
- 更新 `demo/` 的工程、独立代码、模拟设备入口、说明和截图，包含实时曲线、控制命令、字段表格和事件日志。

提供 Windows x64、macOS Apple Silicon（arm64）和 macOS Intel（x64）三个独立运行包，以及各包的 `.zip.sha256` 校验文件。发布流程运行回归测试、原生 GUI 检查和解压后应用启动检查。

下载对应平台的 zip 并解压：Windows 运行 `main.exe`，Mac 打开 `.app`。安装包内置 Python 和 Qt；应用内“一键打包”仍需要 Python 和本机编译工具，Mac 使用 Xcode Command Line Tools。

Mac 安装包未做 Apple Developer ID 签名与公证；Windows 安装包未做 Authenticode 签名。通信验证使用模拟设备和软件测试，实际硬件及驱动仍需按设备协议联调。
