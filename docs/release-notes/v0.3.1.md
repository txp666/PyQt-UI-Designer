- 导出的代码和打包的程序使用导出时设计器的主题色（原来只带浅色 / 深色模式），数值显示也跟随主题色。
- 打包的 macOS 程序使用 `io.github.txp666.pyqtuidesigner.app…` 形式的包标识，不再用应用名；打包的 Windows 程序，版本信息改为应用自己的名字。
- 设计器自己的 macOS 包标识改为 `io.github.txp666.PyQtUIDesigner`，macOS 会把它当作新应用，系统授予的权限可能需要重新确认一次。
- 打包后不再留下空的 `build/main.dist` 文件夹。

## English

- Exported code and packaged programs use the designer's theme colour as set at export time (they took only the light / dark mode before), and numeric displays follow it.
- Packaged macOS programs get a bundle identifier of the form `io.github.txp666.pyqtuidesigner.app…` instead of the app name; packaged Windows programs' version information names the app.
- The designer's own macOS bundle identifier becomes `io.github.txp666.PyQtUIDesigner`; macOS treats it as a new app, so system permissions may need confirming once more.
- Packaging no longer leaves an empty `build/main.dist` folder behind.
