# 视频教程工程

这里是视频教程里一步步搭出来的工程。在设计器左侧点“打开项目”，选择对应的 `.uidp` 文件，就能接着改，或者直接预览运行、导出代码。

视频里演示用的是模拟设备。连接真实设备时，只要下位机按下面的格式收发数据即可。串口参数默认 115200 8N1，第 2 个工程是 9600 8N1；第 10 个工程走以太网，不用串口。

| 工程 | 对应教程 | 数据格式 |
| --- | --- | --- |
| `01-温湿度采集.uidp` | 从零做一个温湿度上位机 | 键值文本 |
| `02-温控仪监控.uidp` | 用 Modbus RTU 读写温控仪 | Modbus RTU |
| `03-电机控制板.uidp` | 解析单片机的 HEX 二进制帧 | 二进制帧 |
| `04-环境监测站.uidp` | JSON 解析与多页面界面 | JSON |
| `05-AT指令调试助手.uidp` | 做一个串口调试助手 | AT 指令 |
| `06-PID调参助手.uidp` | PID 调参上位机 | 键值文本 |
| `07-ADC采集板.uidp` | 原始值换算 | 键值文本 |
| `08-电池放电测试.uidp` | 数据记录与回放 | 键值文本 |
| `10-PLC恒压供水.uidp` | 用 Modbus TCP 监控 PLC | Modbus TCP |

## 01 温湿度采集

下位机每 200 ms 发一行 `temp=26.4,humi=58.2,fan=0`，以换行结尾。

风扇开关发 `FAN_ON` / `FAN_OFF`，以 `\r\n` 结尾。

## 02 温控仪监控

工程里是一张串口卡片（解析模式选 `modbus`）和绑定了寄存器地址的控件，没有 Modbus 卡片：连上串口，程序就按绑定自动读取，不用点按钮。四个显示控件绑定保持寄存器 0–3，实时曲线读 4–5 和 1，合成一块：从站地址 1，上位机每 500 ms 用功能码 03 从地址 0 读 6 个寄存器：

| 地址 | 内容 |
| --- | --- |
| 0 | 实测温度，int16，单位 0.1 °C |
| 1 | 设定温度，uint16，°C，用 06 写入 |
| 2 | 加热功率，uint16，% |
| 3 | 运行状态，0 停止 / 1 运行 |
| 4–5 | 实测温度，float32，寄存器顺序 AB CD |
| 线圈 0 | 启动 / 停止，用 05 写入 |

Modbus 卡片是可选的面板：想改轮询周期（比如 200 ms）、响应超时或默认从站，看轮询状态，或者手动发一条请求时，再放一张 Modbus 卡片即可，见 [docs/protocol.md](../../docs/protocol.md) 的「Modbus 卡片：参数、状态和手动收发」。

## 03 电机控制板

下位机每 100 ms 发一帧 13 字节，多字节数值为小端：

```
AA 55 | 转速 float32 | 目标转速 int16 | 电流 uint16 (mA) | 状态 uint8 | 0D 0A
```

上位机命令使用相同的帧头和帧尾：

- `AA 55 01 01 0D 0A`：启动
- `AA 55 01 00 0D 0A`：停止
- `AA 55 02 <int16 小端> 0D 0A`：设定目标转速

## 04 环境监测站

下位机每 500 ms 发一行 JSON：

```json
{"env": {"temp": 24.6, "humi": 51.2}, "air": {"pm25": 18, "co2": 612},
 "sensors": [{"lux": 320}, {"lux": 295}], "bat": 87, "rssi": -58, "led": 0}
```

LED 开关发 `{"led":1}` / `{"led":0}`。

## 05 AT 指令调试助手

指令以 `\r\n` 结尾，模块执行成功回 `OK`：

- `AT`：测试
- `AT+VER?`：查询版本
- `AT+LED=1` / `AT+LED=0`：LED 开 / 关
- `AT+MODE=1/2/3`：普通 / 省电 / 调试模式
- `AT+NAME=<名称>`：设置名称

## 06 PID 调参助手

下位机每 20 ms 发一行 `tgt=100.0,pos=91.23,kp=3.00,ki=0.00,kd=0.00`，以换行结尾。

上位机命令以 `\r\n` 结尾：

- `KP=300`、`KI=500`、`KD=60`：滑块只能发整数，所以参数放大 100 倍，例如 `KP=300` 就是 Kp = 3.00
- `TARGET=<设定值>`：设定目标值
- `PAUSE=1` / `PAUSE=0`：暂停 / 继续上报

## 07 ADC 采集板

下位机每 100 ms 发一行原始值 `adc0=1985,adc1=310,st=33`，以换行结尾：

| 键 | 内容 | 上位机里的换算 |
| --- | --- | --- |
| `adc0` | 旋钮电压，12 位 ADC，0～4095 对应 0～3.3 V | `value * 3.3 / 4095`，小数位数 2 |
| `adc1` | LM35 温度传感器，每度 10 mV | `value * 330 / 4095` |
| `st` | 状态寄存器：bit0 运行，bit1 加热，bit2 过温，bit5 传感器就绪 | 二进制显示；指示灯用 `(value >> n) & 1` 取位 |

欠压灯用比较表达式 `value * 3.3 / 4095 < 1`，电压低于 1 V 就亮。

加热开关发 `HEAT=1` / `HEAT=0`，以 `\r\n` 结尾。

## 08 电池放电测试

下位机每 200 ms 发一行 `v=3.712,i=1.00,mah=520,run=1`，以换行结尾：v 是电压，i 是电流，mah 是已经放出的容量，run 表示是否在放电。

上位机发 `START` / `STOP` 开始和停止放电，以 `\r\n` 结尾；电压降到 3.0 V 时，下位机自己停下并上报 `run=0`。

数据表格用“逐行记录”记下时间 / v / i / mah；曲线可以保存成 CSV，下次用“加载”把它叠加在当前曲线上对比。

## 10 PLC 恒压供水

PLC 用 Modbus TCP 通信，单元标识（从站地址）为 1。工程里默认连 `127.0.0.1:1502`，那是视频里的模拟 PLC；真实 PLC 的 Modbus TCP 端口一般是 502，在 TCP 卡片里改成 PLC 的 IP 和端口即可。西门子 S7-1200/1500 要先在 PLC 程序里用 `MB_SERVER` 开出 Modbus TCP 服务，其他品牌按各自手册打开 Modbus TCP 从站功能，并把下表的数据映射到对应地址。

工程里是一张 TCP 卡片（解析模式选 `modbus_tcp`）和绑定了寄存器地址的控件，没有 Modbus 卡片。连上 PLC 就自动轮询，不用点按钮：程序按控件的绑定把地址分成三块，每块 500 ms 读一次，一次一条，每条等到 PLC 回应（最多 1000 ms）再发下一条：

```
线圈 0–3            从站 1 功能码 1 地址 0 数量 4
保持寄存器 100–105  从站 1 功能码 3 地址 100 数量 6
保持寄存器 200–201  从站 1 功能码 3 地址 200 数量 2
```

| 地址 | 内容 |
| --- | --- |
| 保持寄存器 100–101 | 出水压力，float32，MPa，寄存器顺序 AB CD |
| 保持寄存器 102–103 | 瞬时流量，float32，m³/h |
| 保持寄存器 104 | 水泵频率，uint16，单位 0.1 Hz |
| 保持寄存器 105 | 水箱液位，uint16，% |
| 保持寄存器 200–201 | 目标压力，float32，MPa；输入框回车后用 16 号功能码写入 |
| 线圈 0 / 1 | 1 号泵 / 2 号泵运行 |
| 线圈 2 | 故障报警 |
| 线圈 3 | 系统启停，开关用 05 号功能码写入 |

显示控件都按寄存器地址绑定（寄存器区选“保持寄存器”或“线圈”），三块地址的数据不会混在一起。要看轮询状态或改周期时，可以再放一张可选的 Modbus 卡片（同 02）。
